📚 How to Use EmbedScape

1️⃣ Load Your Data

Upload a CSV file with text and/or image URLs. Each row will become a point in the visualization.

  • Text column: Text content to embed (optional)
  • Label column: Display name for each item (optional)
  • Image URL column: Links to images (optional)

2️⃣ Configure & Process

Choose your embedding model:

  • Text only: Fast embeddings using MiniLM (text data only)
  • Multimodal: CLIP embeddings (works with text ↔ image search)

The app will generate embeddings, cluster them using k-means, and reduce to 2D with UMAP for visualization.

3️⃣ Semantic Search & Tagging

Text Search: Enter any text query to find semantically similar items.

Image Search: (Multimodal only) Upload an image to find similar text/images.

💡 Tip: Click on individual search results to zoom in and highlight that specific node!

Manual Tagging:

  • Selection modes: Switch to "Single select" or "Multi-select" to tag items
  • Multi-select: Hold Ctrl/Cmd and click to select multiple nodes
  • Add tags: Type a tag name and click "+ Add Tag" to tag selected nodes
  • Color by Tag: Switch visualization coloring from clusters to tags
  • Filter by tags: Select tags to show only those items
  • Tags persist: Your tags are saved with the session JSON file

4️⃣ Interactive Visualization

  • Pan: Click and drag to move around
  • Zoom: Scroll or pinch to zoom in/out
  • Click nodes: View details about each item
  • Colors: Each color represents a different cluster

💾 Save & Load Sessions

Save your embeddings as a .json file to avoid reprocessing. Load it later to continue exploring!

Note: All processing happens in your browser. Your data never leaves your computer!
